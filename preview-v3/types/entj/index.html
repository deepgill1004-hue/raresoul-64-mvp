ENTJ

獅王統御型

自帶行軍表的人

你看到事情就想排順序、定指標、找資源，把混亂變成一條可以推進的線。你同時有很強的方向感，知道這條線最後要通到哪。所以你說話直接、決策快，因為這件事會怎麼走，你早就在腦中跑過了。

美國全國樣本約 1.8%，16 型中第 2 稀有（MBTI Manual 第 3 版常模；台灣無公開同顆粒度數據）

優勢

  • ✦ 能快速抓到瓶頸，並指派誰去解
  • ✦ 目標設了就盯到完成，不容易半途放棄
  • ✦ 亂局中冷靜，反而讓人安心
  • ✦ 講話直，不讓團隊猜你的想法

盲點

  • △ 效率擺第一，把人累壞了還不自知
  • △ 聽不下去慢吞吞的討論，常提前打斷
  • △ 把自己的標準當成全世界的標準
  • △ 很少停下來承認自己累或受傷

在感情裡

你把感情也當成要經營的事：定期約會、討論未來、一起設目標。你的愛是出錢出力、幫對方解決問題。你不太會說細膩的內心話，說起來彆扭，伴侶常覺得你像在開會。適合你的伴侶，是能直接頂回來、也不會被你嚇跑的人。

在工作上

你天生適合帶人、管專案、做營運與經營決策。給你權責和明確目標，你會自己把組織拉起來。你受不了有責任卻沒決定權，也受不了團隊用開會代替做事。你選人的眼光準，但容易拿同一把尺量所有人。

壓力爆表時

壓力下，你會進入命令模式：催進度、挑錯、不聽解釋。更深的時候，你會突然覺得沒人真的懂你，努力都沒被看見。平常的強硬裂出一條縫，可能只在某個深夜爆哭一次，隔天照常開會。

成長方向

下指令前先問一句「你怎麼看」，並真的聽完。學著分辨「慢」和「不努力」是兩件事。把休息排進行程，像排會議一樣硬性，否則身體會替你喊停。你的團隊會因此更敢說真話，問題也會更早浮出來。

最常被誤會的地方

你常被當成愛控制、不近人情。其實你的強勢多半來自責任感，你覺得事情沒人扛就會垮。只要對方拿出道理或數字，你很容易被說服，也會公開承認自己錯了。你最看不起藉口，而不是犯錯。

常被誤認成

  • 常被誤認成 ESTJ：差別在怎麼看制度。ENTJ 先問這條路通到哪，再改制度；ESTJ 先守住現行流程，靠它穩穩運轉。
  • 常被誤認成 INTJ：差別在是否親自下場。ENTJ 要親自調度人和資源；INTJ 寧可在幕後把藍圖畫好，再交給別人執行。
